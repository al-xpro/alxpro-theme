# Security policy

AlxPro Theme is a set of color themes, so it runs very little code. These parts can still
affect your machine or your site:

- [`install.sh`](install.sh), which people run with `curl | bash`;
- the `alxpro-theme` npm package;
- the VS Code extension, on the VS Code Marketplace and Open VSX;
- the release workflow, which publishes all of the above.

## Supported versions

Only the latest release gets fixes.

## Reporting a vulnerability

Please report it privately, not in a public issue:
[report a vulnerability](https://github.com/al-xpro/alxpro-theme/security/advisories/new)
on GitHub (the repository's **Security** tab → **Report a vulnerability**).

Include what's affected, how to reproduce it, and what an attacker could do with it. You'll
get a reply within 7 days. Once it's fixed and released, the advisory is published, with
credit to you if you'd like it.
